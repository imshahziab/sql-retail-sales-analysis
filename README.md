# SQL Retail Sales & Business Intelligence Engine

A comprehensive suite of production-ready SQL scripts designed to extract actionable business metrics, evaluate customer lifetime value (CLV), and track product profitability from relational retail databases.

---

## 📌 Analytical Capabilities
- **Time-Series Financials:** Calculated Month-over-Month (MoM) revenue growth using SQL Window Functions (`LAG`).
- **Customer Segmentation:** Categorized buyers into distinct retention tiers (One-time, Repeat, Loyal) via Common Table Expressions (CTEs).
- **Profitability Breakdown:** Assessed gross sales, net margins, and unit movement per category.
- **High-Value Client Identification:** Tracked top 10 revenue-generating accounts along with Average Order Value (AOV).

---

## 🛠️ Tech Stack & Concepts
- **Language:** SQL (Compatible with PostgreSQL, MySQL, SQLite)
- **Key Techniques:** Window Functions (`OVER`, `LAG`), CTEs (`WITH` clauses), Aggregations (`SUM`, `AVG`, `COUNT`), Conditional Logic (`CASE WHEN`).
